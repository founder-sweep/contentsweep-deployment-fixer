# Deployment Fixer marketing walkthrough

Prepared November 12, 2026. The hosted assessment is live; this new distribution bundle and copy are prepared for review. All cases are owned synthetic source, evaluated by the actual engine. This file ships as `WALKTHROUGH.md` in the bundle.

## Position and offer

Find FastAPI container deployment blockers before granting an agent cloud access. The result is file evidence, configuration gaps and an advisory ECS Express plan. Local tools are free. Saved hosted assessments include five trials per verified organization, then $20/10 plans. A completed supported assessment costs one plan even if blocked. Unsupported, incomplete and platform-failed evaluations consume none. No subscription or automatic replenishment.

Lead audience: maintainers of a single stateless FastAPI container, including developers preparing a client handoff. Infrastructure changes, builds, runtime health verification, automatic fixes and cost quotes are outside this offer. Do not market the product as an automatic deployer. Inspector is a separate optional job/purchase, not a required funnel step.

## Reproduce the assessment

Install the checksum-verified local wheel using `README.md`. From the bundle root:

```sh
deployfixer examples/supported/source --format json
deployfixer examples/blocked/source --format json
deployfixer examples/stateful-unsupported/source --format json
```

| Case | Result to inspect | Hosted credit behavior |
| --- | --- | --- |
| Supported stateless FastAPI | Complete static assessment, detected start/port/health-route evidence, advisory gaps | One completed plan; runtime readiness remains unverified. |
| Uvicorn reload plus explicit root container user | `blocked` on the high-severity reload finding, plus a medium-severity root-user finding; resolve through reviewed edits | One completed plan despite blockers. |
| Source imports a database driver | Scope finding; hosted wrapper returns `unsupported` | No debit. The free local CLI exposes its local scope finding rather than the hosted wrapper's accounting verdict. |

Each folder has uploaded `bundle.json`, `source/`, and `report.json`. The reports are generated by the hosted assessment wrapper, which adds support/accounting semantics to the local planner. Local paths, fingerprints and wrapper fields can differ; compare findings and coverage. The local-only wheel exits 0 for complete analysis even with a `blocked` JSON verdict; inspect that verdict. Incomplete analysis exits 5. No example is built or deployed.
